=========================================================
OBJECTIF
=========================================================

Créer un assistant de configuration (Wizard) utilisant un Stepper Vertical Material UI.

Cet écran permettra de configurer entièrement le moteur comptable.

L'écran fonctionne selon deux modes :

VIEW MODE

Toutes les informations sont consultables uniquement.

Aucune modification.

EDIT MODE

Toutes les étapes deviennent modifiables.

Un bouton

Modifier

fait passer de View à Edit.

Un bouton

Annuler

revient à View.

Un bouton

Enregistrer

sauvegarde toute la configuration.
