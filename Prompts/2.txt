# 6) RÈGLES MÉTIER À CODER ABSOLUMENT

## ouverture de caisse
- caisse active obligatoire
- utilisateur affecté à la caisse
- aucune session ouverte existante sur cette caisse
- montant d’ouverture >= 0

## création opération
- session ouverte obligatoire
- catégorie obligatoire
- catégorie cohérente avec direction
- montant > 0
- mode de paiement obligatoire
- caisse cohérente avec session

## modification opération
- session non clôturée
- opération non supprimée
- droit utilisateur OK

## annulation opération
- soft delete logique uniquement
- recalcul session obligatoire

## fermeture session
- session ouverte obligatoire
- saisie du solde physique
- calcul théorique
- calcul écart
- verrouillage logique session

## calcul du solde théorique
TheoreticalBalance = OpeningBalance + Sum(IN) - Sum(OUT)
en excluant les opérations supprimées logiquement.
