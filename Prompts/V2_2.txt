# 3) MODULE — PIÈCES JOINTES

## Objectif
Permettre d’attacher des fichiers aux opérations, transferts, dépôts, anomalies, validations, imports, etc.

## Contrainte importante
Le projet utilise SQLite locale.
Je veux une stratégie simple et robuste :
- **fichiers stockés sur disque local**
- **métadonnées en base**

## Entité
- Attachment

## Champs minimums
- Id
- FileName
- OriginalFileName
- ContentType
- FileSize
- StoragePath
- EntityType
- EntityId
- UploadedBy
- UploadedAt
- Description

## Règles métier
- whitelist d’extensions
- taille max configurable
- nom de fichier sécurisé
- stockage dans un répertoire applicatif configurable
- possibilité d’attacher à plusieurs types d’entités
- suppression logique ou physique selon la stratégie que tu choisis, mais explique-la

## DTO minimum
- AttachmentDto
- UploadAttachmentResponseDto

## Service
- IAttachmentService / AttachmentService

## API
- GET /api/attachments/{entityType}/{entityId}
- POST /api/attachments/upload
- GET /api/attachments/{id}/download
- DELETE /api/attachments/{id}

## Intégrations attendues
Le module attachments doit pouvoir être utilisé par :
- CashOperation
- CashTransfer
- BankDeposit
- ApprovalRequest
- AnomalyCase
- ImportBatch
- ReconciliationBatch si pertinent
